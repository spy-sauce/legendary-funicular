## Gating semantics

**Old (wave):** Downstream agents wait for upstream `FRUIT_READY` signals before they can begin work. This creates a dependency waterfall where the aggregator cannot start until findings is complete, heal-loop cannot start until aggregator is complete, and so on. The merge order encodes execution order, and agents spend most of their wall-clock time blocked.

**New (contract-freeze):** The moment `NUTRIENTS.md` freezes (all ten contracts locked), every biome can begin simultaneously. Specialists consume frozen contract stubs — type signatures, schema definitions, mock payloads — not upstream code. They implement against the interface, not the implementation. Integration happens at merge time via the deterministic merge order (`audit-findings` → `audit-testers` → `audit-aggregator` → `audit-heal-loop` → `audit-sporenet` → `audit-cli` → `audit-docs`), not execution time. This is what unlocked the full parallel tree: all 22 specialists ran concurrently the instant contracts froze (2026-05-11T19:54:58Z, NUTRIENTS §§1–10).
