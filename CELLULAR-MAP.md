## Parallelism — max-concurrency depth

Gating: **contract-freeze**. All 30 leaves are unblocked the moment `mycelium contracts freeze` has run. Every leaf reads frozen stubs from `NUTRIENTS.md`; nothing waits on code from another biome.

```
wave 1 (all 30 leaves in flight simultaneously)
──────────────────────────────────────────────────────────
telemetry-agent     ████  4 leaves
cicd-agent          █████ 5 leaves
cost-agent          ████  4 leaves
alerting-agent      ████  4 leaves
dashboard-agent     █████ 5 leaves
fleet-agent         ████  4 leaves
docs-agent          ████  4 leaves
                    ─────
total               30 leaves
```

Recommended invocation: `mycelium cultivate -c 30` (full fan-out, no queueing).
With default `-c 50`, all 30 run in one wave; with `-c 10`, three waves of ~10.

## Acceptance gates — what "done" looks like

The cultivation is considered fruited when **all** are true:

1. `mycelium harvest -t 0.8` passes (≥24 of 30 leaves FRUIT_READY).
2. `cd cli && npx tsc --noEmit` passes.
3. `cd cli && npm run build` produces `dist/index.js`.
4. `node cli/dist/index.js --help` lists all existing commands unchanged.
5. Every bundled upgrade still loads: `node cli/dist/index.js upgrades list` clean.
6. `mycelium sporenet serve --port 3333` → `/` renders scale.html with data; `/fleet` renders with at least one card from this run's own JSONL.
7. `.github/actions/mycelium-run/action.yml` is syntactically valid YAML.
8. `DEVELOPER_GUIDE.md` contains new §13 and §14 with no removal of existing sections.

Any failure → `mycelium cultivate --only-biome <failing-biome>` re-runs the subtree.

## What was ruled OUT (scope discipline)

- New aws-sdk dependency — S3 sink is an **adapter shape**; real S3 wiring is a follow-on.
- Auth for the dashboard — localhost assumption; documented but not implemented.
- Real deploy logic — deploy-stg / smoke / deploy-prod are placeholder hooks consuming repos override.
- Cross-organism DAG visualization — fleet view shows cards, not dependencies.
- Real-time budget enforcement — cost tracking estimates, doesn't enforce.
- Email / PagerDuty / Discord sinks — Slack + GitHub only.
- Python / Java orchestration parity — docs clarify these are for **embedding**, not orchestrating.
